# Identity Audit

Reproduction code for the **Identity Audit** of the paper (**Appendix B.7.3**, summarized in Section 3.4).

The audit represents every face with an **ArcFace** identity embedding and measures, in cosine similarity:

- **I2V identity preservation** — mean similarity of each I2V video to its reference frame, and share of videos above the verification threshold $\tau$;
- **T2V similarity to the source subject** — mean similarity of each T2V video to the person of its source video;
- **T2V videos from the same caption** — mean similarity between T2V videos generated by different generators from the same caption;
- **Identity count** — FF++ subjects estimated by clustering their reference frames, documented DFD actors, and T2V videos.

## Pipeline

1. **Embeddings** ([`01_extract_embeddings.py`](01_extract_embeddings.py)) — samples 32 equidistant frames per video, keeps the largest detected face per frame, and averages the normalized per-frame embeddings into one identity embedding per video. Each reference frame, being a single image, yields one embedding.
2. **Analysis** ([`02_identity_analysis.py`](02_identity_analysis.py)) — calibrates the thresholds on the FF++ and DFD reference frames and computes the statistics above.

## Requirements

- Python 3.11
- `insightface`, `onnxruntime-gpu`, `decord`, `opencv-python`, `numpy`, `pandas`

```bash
pip install insightface onnxruntime-gpu decord opencv-python numpy pandas
```

Tested with insightface 1.0.1, onnxruntime-gpu 1.22.0 and decord 0.6.0.

**Model.** The insightface [`buffalo_l`](https://github.com/deepinsight/insightface/tree/master/model_zoo) model pack is downloaded automatically on the first run. Only its face detection (SCRFD-10GF) and recognition (ArcFace ResNet-50 trained on WebFace600K) models are loaded. As stated by insightface, its pretrained models are available for non-commercial research purposes only.

## Step 1 — Embeddings

Run the script once per set, using the set names expected by Step 2:

| Set name | Input |
|---|---|
| `sources_ffpp` | the 1,000 FF++ pristine source videos |
| `sources_dfd` | the 363 DFD pristine source videos |
| `refframes` | the 1,363 I2V reference frames (images) |
| `t2v_<generator>` | the Raw T2V videos of one generator |
| `i2v_<generator>` | the Raw I2V videos of one generator |

Generator slugs: `cogvideox`, `daVinci`, `helios`, `ltx2-3`, `magi-1`, `self-forcing` (T2V only), `skyreels-v2`, `wan2-1`.

```bash
python 01_extract_embeddings.py --video-dir /path/to/ffpp/videos --set-name sources_ffpp --gpu-id 0
python 01_extract_embeddings.py --images-dir /path/to/reference_frames --set-name refframes --gpu-id 0
python 01_extract_embeddings.py --video-dir /path/to/t2v/wan2-1 --set-name t2v_wan2-1 --gpu-id 0
python 01_extract_embeddings.py --video-dir /path/to/i2v/wan2-1 --set-name i2v_wan2-1 --gpu-id 0
```

Step 2 matches each video to its source by file name. A source video and its reference frame share the same stem, and the stem of each generated video starts with the stem of its source video (e.g. `000_wan2-1` for source `000`).

## Step 2 — Analysis

```bash
python 02_identity_analysis.py
```

The script prints the values reported in **Appendix B.7.3** and writes `calibration.csv`, `i2v_preservation.csv`, `t2v_source_similarity.csv` and `summary.txt` to `results/analysis/`.

## Notes

- **Thresholds.** $\tau$ is the 99th percentile of the 363,000 FF++ $\times$ DFD reference-frame pairs, which depict different people by construction (false-match rate 1%). The same-person floor used for clustering is the 1st percentile of the similarity between each pristine source video and its own reference frame.
- **Videos without faces.** Videos with no detected face on any sampled frame are recorded with `frames_with_face = 0` and excluded from the similarity statistics.
- **GPU determinism.** Embeddings computed on a different GPU or run may differ slightly (cosine similarity above 0.9999 with ours), which can move the reported values in the third decimal.
- **Biometric data.** The embeddings are biometric templates of the people depicted in FF++ and DFD and are not distributed. Do not redistribute the ones you compute.
