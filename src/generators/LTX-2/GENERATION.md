# LTX-2.3 Generation

How we generated the LTX-2.3 videos of SynthForensics (1,363 T2V and 1,363 I2V). The overall procedure and the note on reproducibility are in [`../README.md`](../README.md). All commands are run from `src/generators/LTX-2/`.

## Environment

Tested with Python 3.12, PyTorch 2.7.1 (CUDA 12.8), xformers 0.0.31.post1, and flash-attn 2.8.3. The upstream code is vendored in this folder at commit [`9e8a28e`](https://github.com/Lightricks/LTX-2/tree/9e8a28e17ac4dd9e49695223d50753a1ebda36fe). `environment.yml` pins every package of the environment we used.

```bash
conda env create -f environment.yml
conda activate ltx23
pip install flash-attn==2.8.3 --no-build-isolation
pip install --no-deps -e packages/ltx-core -e packages/ltx-pipelines
```

```
models/
├── v2.3/
│   ├── ltx-2.3-22b-dev.safetensors
```

The SHA-256 checksum of every weight file is stored in the `environment` field of each video's metadata.

## Inputs

From the SynthForensics dataset on Hugging Face:

- `captions/{id}.json`: structured caption of each source video (T2V and I2V)
- `I2V/i2v_frames/{id}.png`: reference frame (I2V only)

## Prompt construction

The prompt joins 7 of the 8 caption fields into a single paragraph, in this order: `short_description`, `dense_description`, `background`, `shot_type`, `camera_movement`, `lighting`, `atmosphere`. The `style` field is not used.

## Generation

```bash
# T2V
python generate_t2v.py --captions-dir /path/to/SynthForensics/captions --gpu 0

# I2V
python generate_i2v.py --captions-dir /path/to/SynthForensics/captions \
    --images-dir /path/to/SynthForensics/I2V/i2v_frames --gpu 0
```

`--start-index` and `--end-index` split the sorted caption list across GPUs (e.g. `0`–`681` and `681`–`1363`). Videos whose `.mp4` and `.json` already exist in the output folder are skipped, so an interrupted run can be resumed.

Each video gets a new random seed. In T2V the orientation (landscape or portrait) is drawn from the seed, in I2V it follows the reference frame.

## Settings

| Parameter | Value |
|-----------|-------|
| Pipeline | `ti2vid_two_stages`: stage 1 at half resolution (30 steps), stage 2 with 2x spatial upsampling and distilled LoRA refinement (3 steps) |
| Distilled LoRA strength | 0.5 (the default 1.0 produced flickering) |
| Resolution (W x H) | 1536 x 1024 (landscape) or 1024 x 1536 (portrait) |
| Frames | 121 at 24 fps (about 5 s) |
| Video guidance | CFG 3.0, STG 1.0 on block 28, rescale 0.7 |
| Audio guidance | CFG 7.0, STG 1.0 on block 28, rescale 0.7 |
| Cross-modal guidance | A2V 3.0, V2A 3.0 |
| I2V conditioning | reference frame at index 0, strength 1.0, CRF 0 |
| Precision | bfloat16, no quantization |
| VAE tiling | default |

## Output

Videos are written to `outputs/ltx23_t2v_raw/` and `outputs/ltx23_i2v_raw/` (override with `--output-dir`), with the same file names as in the released dataset (`_i2v` for I2V):

- `{id}_ltx_2-3_t2v.mp4`: H.264 video with the audio track generated by the model
- `{id}_ltx_2-3_t2v.json`: prompt, negative prompt, seed, all hyperparameters, model revisions and checksums, software versions, and GPU

In the released dataset they are under `videos/raw/ltx2-3/` and `metadata/ltx2-3/` of the `T2V/` and `I2V/` folders.
